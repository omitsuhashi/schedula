# 勤務計画は有限の勤務候補と担当配置を同時に最適化する

人数だけを見て出勤者を先に固定すると、必要な技能を持つ人が不足して担当配置に失敗する場合がある。
`roster` は出退勤・休憩を含む有限の勤務候補の選択と、勤務中の担当配置を CP-SAT の同じモデルで決める。
候補方式は入力・検証・探索範囲を明示しやすい一方、候補外の時刻を探索せず、
初期契約は1人1日最大1勤務、日付をまたぐ勤務を対象外とする。

時刻を自由な変数として連続的に探索する構成への変更や夜勤対応では、候補・休憩・日付・履歴の意味を再検討する。
採用元は[ZIP の勤務計画仕様](../sources.md)。最適性の範囲は[入出力契約](../io-contract.md)に記す。
