# 夜勤・分割勤務と再計画を別版の有限候補契約へ拡張する

夜勤・分割勤務、公平性、変更最小化、診断では、勤務日・勤務量・比較元の意味を揃える必要がある。
[ADR-0002](0002-joint-roster-optimization.md) の有限候補と担当配置の同時最適化を維持し、
0.2で一つの候補に1〜4区間を持たせ、最初の開始日を勤務日とする案を提案する。
0.1の1人1日最大1勤務・日跨ぎ拒否は変更しない。

開始日で連勤を数える方式は、夜勤明けに触れたすべての日を勤務日とする方式と結果が異なる。
分割を一候補として扱うことで1勤務日の選択を維持できるが、区間間の非勤務と勤務間の休息を区別する。
期間端を切る方式は勤務量・休息と前後固定情報を追加で定義する必要があるため、
本案は全区間が計画内に収まる候補と、勤務日を明示した計画前履歴に限定する。

公平性は指定対象者の明示目標との非正規化の絶対偏差、変更は新旧計画の勤務・担当状態の時間枠差とする。
固定は必須条件とし、不可能性診断と許可された変更後入力の解を元入力の正式な解から区別する。
これらの尺度は契約比率・変更件数・最小原因を保証しない。
詳細と具体的な期待値は [次期入出力契約](../io-contract-next.md) に記録する。
業務判断は未承認であり、この記録を採用済み・実装済みの根拠にしない。
