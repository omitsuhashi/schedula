# 未完成の基準計画と独立検証を契約0.4の公開境界へ追加する

[Issue #45](https://github.com/omitsuhashi/schedula/issues/45)の既定案に従い、
[ADR-0004](0004-partial-plan-contract.md)の「基準は完全な計画のみ」を0.4で見直す。
不足以外の必須条件を満たす基準を再検証し、担当済み枠を固定する案と通常求解の案を別々に実行する。
固定のない案へ変更最小化を混入させず、同じ業務条件と共通目的で比較できる。

基準入力を際限なくネストする代わりに、公開変換で業務条件と解をコピーし、
元の固定を絶対状態として保存する。比較専用の目的と診断を投影から除き、元入力との対応を残す。
手修正した解は同じ元入力からソルバーなしで公開検証する。
有効性と不足を再計算しても、元の最適性・不足最小性の証明は付与しない。
[ADR-0001](0001-json-first-engine.md)のJSON境界と
[ADR-0002](0002-joint-roster-optimization.md)の同時最適化は維持し、旧版の意味は変更しない。
詳細は[契約0.4](../io-contract-replanning.md)に記す。
