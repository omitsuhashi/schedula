# 継続計画では実績と確定勤務の原区間を保持して計画期間へ投影する

週・月の境界で夜勤を切断すると勤務日・休憩・休息が変わり、勤務量を二重計上し得る。
[Issue #74](https://github.com/omitsuhashi/schedula/issues/74)の実装依頼と
[採用設計](../designs/continuity.md)に基づき、契約0.6の `continuity` 指定時だけ
[ADR-0003](0003-extended-roster-contract.md)の期間内候補限定を見直す。
確認済み実績、確定勤務、新規選択勤務を分離し、原区間を保ったまま計画期間へ集計する。
新規選択は計画内の開始、終了は計画を包含する文脈期間内とする。

有限候補と担当配置の同時最適化、版付きJSON境界、独立検証は維持する。
確定勤務は候補集合から独立した必須状態であり、担当役割は自動固定しない。
文脈直前のアンカーから過去実績・新規勤務・未来確定勤務を接続して休息と連勤を検査する。
現在の規則で過去だけの休息・連勤違反を遡及判定しない。

その代わり、利用側は全従業員の履歴と完全性確認を明示し、未入力の将来勤務は保証範囲外となる。
勤務の出力を計画内へ切り詰めないため、利用側の表示・集計も原区間と計画内投影を区別する必要がある。
0.1〜0.5と0.6のcontinuityなしの意味は変更しない。
期間をずらす基準比較・固定再計画は#75、費用・夜勤休日評価との結合は対応する後続課題で検証する。
公開項目と状態は[契約0.6](../io-contract-continuity.md)に記録する。
