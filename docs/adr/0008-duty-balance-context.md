# 指定区間の目標偏差を確認済みの文脈期間へ広げる

計画内だけの夜勤評価では、前半に夜勤を担った人へ後半も同じ勤務を選び得る。
[Issue #79](https://github.com/omitsuhashi/schedula/issues/79)の実装依頼と
[採用設計](../designs/duty-balance.md)に従い、0.10では評価期間を
確認済みのcontinuity.context_window内へ広げる。
[ADR-0003](0003-extended-roster-contract.md)の期間内限定を、
[ADR-0006](0006-continuity-original-intervals.md)の原区間保持と投影により評価にも見直す。

過去実績・未来の確定勤務・境界をまたぐ選択勤務を一度ずつ集計し、明示目標との絶対偏差を求める。
利用側は全従業員の実績と確定勤務の完全性を確認し、未確認を0へ補完しない。
範囲・目標・履歴の真正性は利用側が管理する。未来の未確定勤務は予測しない。

その代わり、新しい契約版の選択と確認済み履歴の入力が必要になる。
既存fairness・費用はW内の尺度を保ち、0.9までの受理範囲と意味は変更しない。
有限候補・不足とpriorityの優先・固定保持・探索に依存しない検証を維持する。
期間分割は勤務分数の加算を保証する範囲で検証し、分割最適化と通し最適化の同値は保証しない。
