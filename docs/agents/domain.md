# ドメイン文書

このリポジトリは single-context 構成を採用する。

## コードを探索する前に読むもの

- リポジトリ直下の `GLOSSARY.md`
- 作業対象に関係する `docs/adr/` の設計判断

将来 `GLOSSARY-MAP.md` が存在する場合は、
そこから作業対象に関係する用語集を読み取る。

文書が存在しない場合は、そのまま作業を進める。
不在を問題として報告したり、先に作成を提案したりしない。
用語や設計判断が確定した際に domain-modeling スキルが作成する。

## 配置

- 用語集：`GLOSSARY.md`
- 設計判断の記録：`docs/adr/`

## 用語の使用

Issue、提案、仮説、テスト名などでドメイン概念を記述するときは、
用語集で定義された名称を使う。

必要な概念が未定義の場合は、プロジェクトにない概念を
持ち込んでいないか確認し、実際の不足は domain-modeling に伝える。

## 設計判断との矛盾

既存の ADR と矛盾する提案では、該当 ADR と再検討の理由を明示する。

## 言語

ドキュメント本文は日本語で記述する。
識別子、コマンド、コードなどは原表記を保持する。
