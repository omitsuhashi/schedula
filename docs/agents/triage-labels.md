# Triage ラベル

スキルが使う役割と、このリポジトリのラベルを対応付ける。

| 役割 | 使用するラベル | 意味 |
| --- | --- | --- |
| needs-triage | needs-triage | メンテナーによる評価が必要 |
| needs-info | needs-info | 報告者からの追加情報を待っている |
| ready-for-agent | ready-for-agent | 仕様が揃い、エージェントが実装できる |
| ready-for-human | ready-for-human | 人による実装が必要 |
| wontfix | wontfix | 対応しない |

スキルが役割を指定した場合は、対応するラベルを使用する。
運用上の名称を変更する場合は、この表を更新する。
