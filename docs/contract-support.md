# 契約と配布物のサポート方針

現在のJSON契約は0.15です。通常実行・Schema取得・公開型・CLI・Adapter・デモ・配布物は同じ契約を使います。
旧版や未知版は暗黙変換せず拒否します。パッケージ版、JSON契約版、Adapter外側形式版、アプリDB版を別々に記録します。
現在の入力と採用境界は[現行契約](io-contract-current.md)、固定成果物の作り方は[配布方針](distribution.md)を参照します。

## 変更する際に決めること

変更を実装するIssueで、受け入れる入力・既定値・出力・証明・拒否条件と利用側への影響を明記します。
配列順、欠落/null/空/0、日時・尺度、任意項目、保存記録、公開型、終了コード、backend能力を含めて比較します。
同じ入力が異なる必須条件・需要・目的・状態・証明を持つ変更は破壊的変更です。
任意項目の追加でも、未知項目拒否、型のunion、出力の必須欄、保存ハッシュを含む利用側の互換性を確認します。

| 変更 | 版と検証 |
| --- | --- |
| 意味を保った不具合修正・内部整理 | 同じ契約の固定回帰を通す。変更の入力条件・診断と利用側影響をIssue/PRへ記録 |
| 互換な機能追加 | 既定入力の意味が同じことを確認。Schema・型・求解・独立検証・CLI・保存・利用側を同時に更新 |
| 入力・出力・意味・対応範囲の破壊的変更 | 新しい形状・意味には別のJSON契約版を、公開API・対応終了には識別できるパッケージ版を決め、移行・旧版対応・終了条件を同時に承認 |
| 依存版・Python対応環境の変更 | 契約の意味と別に、lock・隔離wheel/sdist・base/cp-sat・利用側固定依存を検証 |

## 旧契約の移行と終了条件

新契約を作る際、旧契約の保守期間・対象環境・終了日または終了条件・責任者を明示します。
旧契約を永久に受け付ける前提にせず、保存データと利用アプリの棚卸しを行います。
未確認を利用ゼロとは扱わず、調査範囲・所有者の回答・確認日・未解決事項を記録します。

終了には次の条件を揃えます。

1. 全業務機能の意味を新契約へ対応付け、現在契約の既定値・独立回帰基準を固定する。
2. 確認したデータを別出力へ明示移行し、失敗・再実行でも原本や既存セッションを保護する。
3. 不足・履歴・候補ID・元基準・固定・目的順・確認失効を保つ。新しい履歴の事実を推測せず、必要な確認で止める。
4. 原Request/Response/record/run_id・版・依存・SHAを過去証拠として保持し、現在verifyの結果を別に保存する。
5. CLI・公開型・Schema・例・デモ・配布物・利用アプリの固定依存・保存・表示・採用・再計画を検証する。
6. 全体回帰・base/cp-sat・隔離導入・型・実ブラウザー・固定規模の性能/解品質比較の結果を残す。
7. 旧版拒否と失敗応答の契約を明示し、一時変換コードを残すか検証後に撤去するかを承認する。

性能基準を超えた場合は自動合格にせず、同条件の基点と変更後を再測定して原因を調べます。
許容値や退行受け入れの変更は、所有者の判断と根拠・残る影響を記録します。
未知版・不完全な履歴・非互換pinを救済するために通常入口を勝手に補完しません。

## 今回の0.15一本化

Issue #105では対象をリポジトリ内の例・試験に限定する所有者回答を記録し、#109/#110/#125で
Request・解・Draft・実行記録・JSON/SQLite保存往復の明示移行を検証しました。
一回限りの移行スクリプト・専用試験・旧入力fixtureは承認どおり撤去し、固定commit・SHA台帳・PR・結果を履歴に残します。
旧契約サポートの継続と、公開PyPI/GitHub Release/実顧客デプロイは今回の完了に含めません。

2026-10-09の利用者回答により、この作業のCI成功基準にはGitHub workflowと同じ検査のローカル成功を採用します。
GitHub Actionsの実行結果は別に記録し、失敗したActionsを成功と表示しません。
この採用判断はリポジトリ保護の無断変更や、必須チェックの管理者回避を認めるものではありません。

## 履歴文書の扱い

旧版追加時のio-contract文書、設計案、測定記録、ADRは当時の判断と証拠として保持します。
旧文書を導入順に読むことを現行仕様の理解の前提にせず、README・全体像から現行契約へ誘導します。
履歴にある旧版の正常実行・旧型名・旧コマンドは現在のサポート範囲ではありません。
履歴資材の撤去後も、固定commitへのリンクで原内容と原SHAを確認できます。
